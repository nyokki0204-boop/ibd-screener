# 急伸・相対強度スクリーナー

マネックス取扱米国株の中から、前日比、価格、出来高、約1年の相対強度、52週安値からの上昇率で候補を抽出します。抽出条件の数値は従来どおりです。

## Webアプリ（Streamlit不要）

ルートの `index.html` は保存済みCSVをブラウザで読む静的画面です。GitHub Pagesを `main` ブランチの `/ (root)` から公開すると、通常は `https://nyokki0204-boop.github.io/ibd-screener/` で開けます。初回はリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** が必要です。公開URLの表示と実際の画面読み込みを確認するまでは、公開完了とは見なしません。

iPhoneでは公開URLをSafariで開き、共有 →「ホーム画面に追加」でアプリのように起動できます。表示データはGitHubに保存されたスキャン結果をその都度読み込み、端末に株価データを保存しません。マイチャートのURL設定のみ端末内に保存します。

ローカル確認では `python -m http.server 8765` を起動して `http://localhost:8765/` を開きます。`file://` で直接開くとCSVの読み込みがブラウザに拒否される場合があります。

## 従来のStreamlit画面

```bash
pip install -r requirements.txt
streamlit run app.py
```

GitHub Actions は米国市場の月〜金の引け後、日本時間の朝7時にスキャンし、提供元の更新遅延に備えて朝11時に再試行します。米国の休場日には前回の取引日が残ります。`data/last_updated.txt` は実行日ではなく米国市場の取引日です。

## 指標の意味

- `RS`：取得できた対象銘柄の**約1年騰落率の順位**を1〜99で表示。IBD社のRS Ratingそのものではありません。取得銘柄の構成が変わると順位も変わります。
- `RelVol`：当日の出来高 ÷ 当日を除く直近50取引日の平均出来高。
- セクター通過率：条件を通過した銘柄数 ÷ その日に価格データを取得できた同セクターの銘柄数。新しい `data/sector_metrics.csv` は次回の正常なスキャンから蓄積します。過去の分母は復元できないため、古いセクター件数履歴は別に表示します。
- `直近5日`：現在の取引日を含む直近5取引日の抽出回数。過去に抽出の記録がない銘柄には `NEW` を表示します（全市場で新規上場という意味ではありません）。

銘柄の取得成功率が80%未満、またはNYSEカレンダーで確定済みの取引日と取得日が一致しないときはスキャンを失敗とし、前回の正常な結果を保持します。最新の試行状況は `data/scan_status.json` に記録され、両画面に表示されます。データ提供元が1日遅れた場合は、再試行しても追いつくまで更新されません。

## マイチャート連携

画面の設定欄にマイチャートの**公開URL**を入れると、各行の「開く」から `?ticker=NVDA` などを付けて開けます。デプロイ済みマイチャートURLを環境変数 `MYCHART_URL` に指定すると、入力を省けます。連携先の `mychart` 側にも `ticker` パラメータの対応が必要です。URLが未設定の場合、このリンクは表示しません。
